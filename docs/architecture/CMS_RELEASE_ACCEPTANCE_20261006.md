# Inner Animal CMS — anti-slop acceptance register

Decision: **No alternate “Edit Site” slide-in editor.** Source demos do not own merchant publication.

| ID | Gate | Evidence before done |
|---|---|---|
| STR-01 | Exactly eight visible Stories layers inventoried | Source/DOM baseline tracks announcement, header, intro, feature, card deck, gallery, film, footer |
| STR-02 | Original design preserved | Identical renderer IDs and stable geometry, media, focal, motion/scroll; changed visual props explicitly reviewed |
| STR-03 | Legible dark cinematic copy | Contrast test of source feature title, paragraph, links on inverse surface |
| STR-04 | No public legacy editor | No Edit Site trigger, drawer, localStorage authoring pathway in Stories runtime |
| STR-05 | Typed reusable content | Project/Milestone/Story entries with reference pickers, structured field validation |
| STR-06 | Source binding | Same Project title and gallery asset in two independently styled pages via typed binding |
| STR-07 | Global ownership | Announcement, header, footer altered once in one GUI and reflected in every template |
| STR-08 | Template route | Merchant creates /stories/:slug through authenticated UI, correct route/SEO/permissions |
| STR-09 | Persistence | Reload/second browser returns same approved draft revision from D1/R2 |
| STR-10 | Reliable publishing | Concurrent edit rejection, staged R2, immutable snapshot, D1 pointer switch, KV recovery, rollback |
| STR-11 | Portable consuming theme | FNF and independent SDK app load same pinned renderer, stylesheet/motion and content references |
| STR-12 | No unintended changes | Existing Shop/Home/other sites exactly as before; tests for default and reduced-motion |

Release vocabulary: **source extracted**, **renderer-backed**, **local editable**, **cloud persisted**, **published**, **portable consumer proven**, **production accepted** are different states. Never call extracted source a full finished CMS page, or treat test fixture success as customer-ready.
